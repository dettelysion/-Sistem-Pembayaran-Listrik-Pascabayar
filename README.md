# Sistem Pembayaran Listrik Pascabayar

## Deskripsi
Sistem Pembayaran Listrik Pascabayar merupakan aplikasi berbasis web yang dibuat untuk membantu proses pengelolaan data pelanggan dan pembayaran tagihan listrik pascabayar.

## Teknologi yang Digunakan
- PHP Native
- MySQL
- HTML
- CSS
- Python
- XAMPP
- Visual Studio Code

## Fitur Aplikasi
- Login dan autentikasi pengguna
- Registrasi pelanggan
- Pengelolaan data pelanggan
- Pengelolaan tagihan listrik
- Pengelolaan pembayaran
- [Tambahkan fitur lain sesuai aplikasi]

## Hak Akses Pengguna
- Admin
- Petugas
- Pelanggan

## Cara Menjalankan Aplikasi
1. Install XAMPP.
2. Jalankan Apache dan MySQL.
3. Salin folder proyek ke dalam folder `htdocs`.
4. Buka phpMyAdmin.
5. Buat database dengan nama `listrik`.
6. Import file `listrik.sql`.
7. Buat file `koneksi.php` berdasarkan konfigurasi database lokal.
8. Buka browser dan akses `http://localhost/web_pembayaran_listrik/`.
